1-Minute Backtesting

    
Spot-only strategy. Strategy and execution both use 1-minute NIFTY/BANKNIFTY spot candles. No options data is requested.

    

    

    
Intrabar ambiguity: when both Stop Loss and Target are touched within the same 1-minute candle, Stop Loss is assumed to occur first. The same conservative rule applies to a breakout candle.

    
EOD exit leaves the consecutive-SL counter unchanged; TARGET resets it, SL increments it, and the counter resets each trading day. Unresolved trades close at the 15:14 candle close (15:15). Intrabar event timestamps use candle completion times, so holding times are minute-level estimates. EOD exits are excluded from resolved win/loss rates and expectancy. Signal counts include all qualifying candles; pending setups count only those accepted while flat and unblocked.
